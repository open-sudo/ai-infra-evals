# AI Infra Evals

This repo contains experiments that measure how reliably AI can perform real infrastructure work across Linux, networking, clustering, security, and distributed systems.

The broader mission is to understand when AI-generated infrastructure work can be trusted.

That means looking beyond whether an agent produced a plausible answer or reached a working state once. The focus is on reliability, repeatability, security, persistence, resilience, and the quality of the system left behind.

The long-term goal is to build a body of evidence around a simple question:

> **Can AI be trusted to operate real infrastructure?**
